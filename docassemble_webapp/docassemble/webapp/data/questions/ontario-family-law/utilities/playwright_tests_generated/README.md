## Troubleshooting

### Common Issues

1. **Tests timing out**
   - Increase timeout in `playwright.config.js`
   - Check if Docassemble server is responsive

2. **Element not found**
   - Interview structure may have changed
   - Regenerate tests using `playwright_test_generator.py`

3. **Validation errors**
   - Check test data format (dates, postal codes)
   - Verify field names match interview

4. **Save/resume failing**
   - Ensure Docassemble has sessions enabled
   - Check user permissions
